# 🚗 Drom Filter - Telegram Mini App

Telegram Mini App для поиска автомобилей в стиле сайта Drom.ru с расширенными фильтрами и удобным интерфейсом.

## 📱 Описание

Это полнофункциональное веб-приложение для фильтрации автомобилей, созданное специально для интеграции с Telegram ботом. Приложение предоставляет пользователям удобный интерфейс для поиска автомобилей по различным критериям.

## ✨ Возможности

### 🔍 Фильтры поиска
- **Марка и модель** - связанные выпадающие списки с базой из 15 марок
- **Год выпуска** - быстрые кнопки + точный выбор диапазона
- **Цена** - популярные диапазоны + ручной ввод
- **Регион** - 16 регионов России
- **Тип кузова** - множественный выбор (10 типов)
- **Технические характеристики**:
  - Коробка передач (4 типа)
  - Объём двигателя (диапазон)
  - Привод (3 типа)
  - Тип топлива (6 типов)
  - Пробег (диапазон)
  - Цвет (12 цветов)
  - Дополнительные фильтры

### 🎨 Дизайн
- **Сине-индиговая градиентная палитра** в стиле Drom.ru
- **Адаптивный дизайн** для мобильных устройств
- **Фиксированный хедер и футер**
- **Белые карточки** с тенями и скруглениями
- **Анимации и переходы**

### 🚗 База данных автомобилей
- **15 марок**: Toyota, Nissan, Honda, Mazda, Mitsubishi, Subaru, BMW, Mercedes-Benz, Audi, Volkswagen, Hyundai, Kia, Chevrolet, Ford, Lexus
- **10-16 моделей** для каждой марки
- **Автоматическая загрузка** моделей при выборе марки

## 🛠 Технологии

- **React 18** - через CDN (без сборки)
- **Tailwind CSS** - для стилизации
- **Lucide Icons** - для иконок
- **Babel** - для JSX транспиляции
- **Telegram WebApp API** - для интеграции с Telegram

## 🚀 Установка и запуск

### Локальный запуск
1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/drom-filter-mini-app.git
cd drom-filter-mini-app
```

2. Запустите локальный сервер:
```bash
python3 -m http.server 8080
```

3. Откройте браузер по адресу: `http://localhost:8080`

### Интеграция с Telegram ботом

1. **Создайте бота** через [@BotFather](https://t.me/BotFather):
   ```
   /newbot
   ```

2. **Создайте Mini App** через [@BotFather](https://t.me/BotFather):
   ```
   /newapp
   ```

3. **Настройте веб-хостинг**:
   - Загрузите файлы на GitHub Pages, Vercel, Netlify или другой хостинг
   - Получите публичный URL

4. **Подключите Mini App к боту**:
   - Введите URL вашего приложения в @BotFather
   - Настройте кнопку меню для запуска Mini App

## 📱 Использование

### В Telegram
1. Откройте бота в Telegram
2. Нажмите кнопку "Поиск автомобилей" или команду `/start`
3. Используйте фильтры для поиска
4. Нажмите "Показать объявления"

### В браузере
1. Откройте `index.html` в браузере
2. Используйте все функции приложения
3. Результаты поиска отображаются в консоли браузера

## 📊 Функциональность

### State Management
Приложение использует React hooks для управления состоянием:
- `useState` для хранения фильтров
- Автоматическое обновление связанных полей
- Валидация и обработка ошибок

### Интеграция с Telegram
- Автоматическая инициализация Telegram WebApp API
- Отправка данных боту через `sendData()`
- Показ результатов через `showAlert()`
- Настройка цветов и поведения

### Адаптивность
- Mobile-first подход
- Адаптивные сетки и отступы
- Оптимизация для сенсорных экранов
- Поддержка всех размеров экранов
